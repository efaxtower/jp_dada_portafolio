## 📋 ¿Qué es esto?

Mi portafolio personal con **estilo Dadá**. Un caos ordenado donde muestro:

- 🛒 **SindroMerchado** - Sistema de supermercado con microservicios
- 🥖 **Sistema de Panadería** - En uso por mi papá
- 💻 **Beep Jesus Pro** - Script Bash para Linux
- 🏥 **Dra. Victoria** - Sitio web médico
- 🖥️ **Mi Servidor Local** - LAMP + Samba + Cockpit

**No soy experto, soy un aprendiz que construye cosas reales.**

## 🎨 Características del Diseño

| Estilo | Aplicación |
|--------|------------|
| **Dadá** | Rotaciones aleatorias, colores caóticos, elementos "rotos" |
| **Brutalismo Leve** | Bordes gruesos, sombras tipo "cartel" |
| **Glassmorfismo** | Fondos con desenfoque y transparencia |
| **Neumorfismo** | Sombras suaves en tarjetas |
| **Estilo Suizo** | Limpieza, jerarquía y grid en secciones |
| **Liquid Glass** | Efectos de fondo con desenfoque extremo |
